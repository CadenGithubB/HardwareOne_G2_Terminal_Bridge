HardwareOne Connect

This tool controls the HardwareOne relay and HardwareOne Terminal host, part of HardwareOne G2 Terminal Bridge. Prepare and pair the services before using the launcher. The device must reach the host over Wi-Fi.

Everyday use

  1. Choose Start both. Already-running services are reused.
  2. Wake the HardwareOne device and paired G2 glasses, then open Terminal from the glasses' side menu.
  3. After restarting the host, close and reopen Terminal on the glasses.
  4. Choose Stop both to stop the relay and Terminal host. Nothing starts automatically at login. Closing Terminal on the glasses closes its view; use its explicit Interrupt action to stop an agent's current work.

Connection details

The launcher's ? panel reads the current endpoint from your private local configuration. Use model openclaw/main.

Copy device key copies the existing relay device credential only when you choose that action. Paste it privately into the device's HTTP relay token setting (llmhttptoken), then clear the clipboard by copying something else. The device login password, OpenClaw Gateway token, host bridge token and paired private identity are separate credentials. Keep host credentials on the host.

If reconfiguring the device, use the displayed endpoint for llmhttpurl, openclaw/main for llmhttpmodel, and retain the existing relay CA in llmhttpca. HTTPS needs a valid device clock. The device connects through the relay; it does not connect directly to the host's local port.

If it does not connect

  1. Check that both services are running and the host is awake.
  2. Check device Wi-Fi, wake the glasses and reopen Terminal.
  3. For certificate errors, check the device clock and saved relay CA. Keep HTTPS verification enabled.
  4. For a host pairing error, run the existing private connection check: 
    node "$HOME/.local/share/hardwareone-g2-terminal-bridge/start.mjs" --check
    Inspect the public device ID and exact pending request before approving it. Routine updates preserve pairing; do not initialize a replacement identity.
