HardwareOne G2 Terminal Bridge

Prepare and pair the relay and Terminal host before using the launcher. The HardwareOne device must be able to reach your host over Wi-Fi.

Everyday use

Choose Start both, wake the device and G2 glasses, then open Terminal on the glasses. Choose Stop both to stop the relay and Terminal host. Nothing starts automatically at login.

Connection details

The launcher's setup dialog reads the endpoint from your private local configuration. Its Copy device key action copies only the relay device credential to the clipboard. Paste it into the device's relay setting and clear the clipboard afterward. It is different from the OpenClaw Gateway token and any device account password.

After an update

Close and reopen Terminal on the glasses after the host restarts. Keep the existing private configuration and identity files.
